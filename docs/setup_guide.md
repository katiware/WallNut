# WallNut セットアップ＆運用手順書 (Setup & Play Guide)

本ドキュメントは、全身ポーズアクションゲーム **WallNut** をゼロからセットアップし、SlimeVR実機と連携してプロジェクターでプレイするまでの完全な手順書です。  
コードで自動化されているエディタ機能の使い方から、**Unity Editor上で手動配置・確認が必要なオブジェクト設定**、**SlimeVR Serverの設定**、**現場でのキャリブレーション手順**、**トラブルシューティング**まで網羅しています。

## 1. システム要件・プレイ環境

* **Unity バージョン**: `Unity 2022.3.62f1` (または 2022.3 LTS)
* **ハードウェア**:
  * ゲーミングPC (Windows 10 / 11)
  * 大画面プロジェクター (または大型モニター: 推奨解像度 1920x1080, 16:9)
  * **VRゴーグル**: **不使用**（プレイヤーはプロジェクター画面を見てプレイします）
* **トラッカー構成 (計7点・頭なし)**:
  * **胸 (Chest)**: 1点 (チェストハーネス等で固定)
  * **両手 (Hands)**: 2点 (コントローラまたは手で握りこみ)
  * **両膝 (Knees)**: 2点 (膝上または膝下にバンド固定)
  * **両足首 (Feet / Ankles)**: 2点 (足首または靴の上に固定)
  * ※頭部 (Head) にはトラッカーを装着しません。

## 2. SlimeVR 側の初期設定 (重要)

SlimeVR Server が Unity に正しく OSC データを送信するための設定です。

### ① トラッカー送受信トグル
SlimeVR Server のメニュー「設定」→「OSC」内の **「トラッカー データの送受信を切り替える」** で以下をONにします：
* **胸**: **ON**
* **腰**: **ON** (装着していればON、無くても可)
* **膝**: **ON**
* **足**: **ON**
* **肘 (または手)**: **ON**

### ② VRChat OSCトラッカー設定 (必須)
「設定」→「OSC」内の **「VRChat OSCトラッカー」** を設定します：
* **有効**: **ON (有効化)**
* **Enable OSCQuery**: **OFF (無効)**
* **ポートイン**: `9001`
* **ポートアウト**: **`9000`** (Unity側の受信ポートと一致)
* **ネットワークアドレス**: **`127.0.0.1`** (同一PC内で動かす場合)

### ③ OSCルーター設定 (注意: 必ずOFF)
「設定」→「OSC」内の **「OSCルーター」**：
* **有効**: **OFF (無効)**  
  > ⚠️ **注意**: OSCルーターを有効にしてポートアウトを 9000 にすると、VRChat OSC とポートが重複してパケットが競合します。必ず **OFF** にしてください。

## 3. Unity シーン構築・オブジェクト設置手順

コードで自動生成されない基礎オブジェクト（床・ライティング・階層）の設置手順です。  
新規シーンを作成する場合、または既存の `SampleScene` を確認する場合は以下の構成になっているか確認してください。

### シーンのヒエラルキー構成図
```text
SampleScene
├── Directional Light          (シーン照明)
├── Floor / Ground             (足元の床: 手動作成)
├── Main Camera                (最適カメラ: Toolsで自動設定)
├── DummyCharacter             (プレイヤー人形: Toolsで自動生成)
│   ├── Spine
│   │   ├── HeadBone (赤い鼻付き)
│   │   ├── LeftArmBone
│   │   └── RightArmBone
│   ├── LeftHipBone
│   │   └── LeftFootBone
│   └── RightHipBone
│       └── RightFootBone
├── GameManager                (ゲーム進行管理: 空オブジェクト + スクリプト)
│   ├── SlimeVRTestReceiver    (OSC受信機: 同一オブジェクトまたは子)
│   └── SlimeVRMockSender      (テスト用擬似送信機)
└── Canvas                     (プロジェクター用UI: Toolsで自動生成)
    ├── TitlePanel
    ├── CountdownPanel
    ├── InGameHUD
    └── ResultPanel
```

### ① 床 (Ground / Floor) の手動作成
壁が流れてくる地面を作成します。
1. Hierarchy 上で右クリック ➡ `3D Object` ➡ `Cube` を作成。
2. 名前を `Floor` に変更。
3. Transform を以下のように設定：
   * **Position**: `X = 0, Y = -0.05, Z = 5`
   * **Rotation**: `X = 0, Y = 0, Z = 0`
   * **Scale**: `X = 10, Y = 0.1, Z = 30` (奥から手前まで十分な長さ)
4. 必要に応じて濃いグレーやダークブルーのマテリアルを適用（人形や穴あき壁が見やすくなります）。

### ② ライティング (Directional Light) の確認
1. `Directional Light` がシーンに存在することを確認。
2. Transform:
   * **Rotation**: `X = 50, Y = -30, Z = 0`
   * **Color**: 白または薄い暖色、**Intensity**: `1.0`

## 4. ワンクリック自動生成ツールの実行順序

Unity の上部メニューバー **「Tools」** から、以下の順番でクリックするだけで必要なオブジェクト・UI・プレハブが自動構築されます。

```text
[Unity上部メニュー]
Tools
 ├── 1. Build All Wall Prefabs   (全7ポーズの穴あき壁プレハブを一括生成)
 ├── 2. Build Dummy Character    (7点ボーン構造のプレイヤー人形を自動生成)
 ├── 3. Build Projector UI       (大画面UI・Canvasを一括生成＆自動バインド)
 └── 4. Setup Optimal Camera     (プロジェクター最適カメラ位置に一発調整)
```

1. **`Tools` ➡ `Build All Wall Prefabs`**
   * `Assets/Prefabs/` 内に、人形のサイズ（全幅2.3m × 全高2.3m）に完全一致した穴あき壁プレハブ（全7種類）が一括生成・更新されます。
2. **`Tools` ➡ `Build Dummy Character`**
   * 原点 `(0, 0, 0)` にダミー人形が生成されます。
   * 胸・両腕・両膝・両足首・頭のボーン参照が `PlayerDummy` および `SlimeVRTestReceiver` へ自動バインドされます。
3. **`Tools` ➡ `Build Projector UI`**
   * 1920x1080 最適化の大画面UIが Canvas に生成され、クリックイベントやフォールバックが自動接続されます。
4. **`Tools` ➡ `Setup Optimal Camera`**
   * `Main Camera` が推奨位置 `(X: 0, Y: 1.4, Z: -3.2)`、見下ろし角 `5度`、FOV `55` に設定されます。

## 5. 手動確認・インスペクター設定項目

自動生成後、以下のコンポーネント設定を確認してください。

### ① GameManager オブジェクトの確認
Hierarchy の `GameManager` オブジェクトを選択し、Inspector を確認：
* **Wall Prefabs**: `Assets/Prefabs/` 内の壁プレハブ（`Wall_0_Stand` 〜 `Wall_6_Flamingo` の7個）が設定されているか確認（※空でも実行時に自動ロードされますが、設定しておくと安全です）。
* **Spawn Position**: `X: 0, Y: 0, Z: 15` (足元Y=0、奥Z=15から迫ってきます)
* **Max Walls**: `10` (1ステージあたりの壁の枚数)

### ② SlimeVRTestReceiver の設定確認
`GameManager` (または `SlimeVRTestReceiver` がアタッチされたオブジェクト) の Inspector：
* **Port**: `9000`
* **Auto Assign Tracker Ids**: `true` (チェックON)
* **Tracker Timeout**: `3.0`
* **Position Multiplier**: `1.0` (しゃがみ沈み込み倍率)
* **Use Position For Arms**: `true` (チェックON: 握りこみ手の位置で腕が直感追従)
* **Facing Yaw Offset**: `0` (※もしゲーム内で腕の左右が逆転する場合は `180` に設定)

### ③ SlimeVRMockSender の確認
* **Enable Mock Sending**: **OFF (チェックなし)**
  > 実機 SlimeVR を使用する際は、ダミーパケットの衝突を防ぐため必ず OFF にしてください。

## 6. プレイ・キャリブレーション手順

### ① ゲームの起動
1. Unity の Game ビューの解像度を **`1920x1080` (16:9)** に設定。
2. Unity 上部の **「Play (再生)」** ボタンを押す。
3. 画面左下に **「📡 SlimeVR 受信モニター」** が表示されます：
   * `ポート 9000: 受信中 ● (通信正常)` と緑色で表示されていることを確認。
   * トラッカーが動くと、`胸` `左手` `右手` `左足` `右足` などのランプが 🟢 に点灯します。

### ② 身長・姿勢キャリブレーション (極めて重要)
1. プレイヤーは **プロジェクター画面の正面（Z = 0 地点）** に立ちます。
2. **腕を自然に下ろし、足をまっすぐ伸ばして直立** します。
3. キーボードの **`[C]` キー**（またはタイトル画面の「キャリブレーション」ボタン）を押します。
4. 画面上に **`[CALIBRATION OK]`** と表示され、キャリブレーションが完了します。
   * この直立姿勢が「基準（ゼロ点）」として記録され、バンザイ・しゃがみ・片足立ちなどの判定が正確に行われるようになります。

### ③ ゲームスタート
1. タイトル画面で難易度を選択：
   * **[EASY]** (キーボード: `1` または `E`): 壁速度 3.5m/s (初心者向け)
   * **[NORMAL]** (キーボード: `2` または `N` / `Space` / `Enter`): 壁速度 5.0m/s (標準)
   * **[HARD]** (キーボード: `3` または `H`): 壁速度 7.5m/s (上級者向け)
2. カウントダウン（3, 2, 1, START!）後、壁が奥から迫ってきます。
3. 壁の穴の形に合わせてポーズをとってください！

## 7. ポーズ一覧と判定のコツ (全7種)

壁の穴の形と、判定システムが認識する条件です。

| ID | ポーズ名 | 壁の色 | 動作のコツ・判定条件 |
|:---:|:---|:---:|:---|
| **0** | **STAND (棒立ち)** | **白** | 両腕を下げ、直立します。中央の縦長スリット穴を通り抜けます。 |
| **1** | **BANZAI (バンザイ)** | **赤** | 握りこんだ両手を肩より高く上げます。腕がV字〜垂直に上がると判定。 |
| **2** | **SQUAT (しゃがみ)** | **青** | 膝を曲げて腰を落とします。胸の沈み込み(20cm以上)または両足の曲がりで判定。 |
| **3** | **T-POSE (Tポーズ)** | **緑** | 両腕を真横に水平に広げます。手の高さが肩付近かつ両手の横幅が広いと判定。 |
| **4** | **RIGHT ARM UP (右腕上げ)** | **黄** | 右手だけを高く上げ、左手は下げておきます。非対称ポーズ。 |
| **5** | **LEFT ARM UP (左腕上げ)** | **シアン** | 左手だけを高く上げ、右手は下げておきます。非対称ポーズ。 |
| **6** | **FLAMINGO (片足立ち)** | **マゼンタ** | 腕は下ろしたまま、片方の足（膝）だけをしっかり曲げて持ち上げます。 |

## 8. トラブルシューティング

### Q1. 左下のモニターに「ポート 9000: バインド失敗」と赤字で表示される
* **原因**: 前回の再生終了時にソケットが閉じきれず残っているか、他アプリがポート 9000 を専有しています。
* **対処法**:
  1. Unity Editor を一度完全に終了し、再起動してください。
  2. SlimeVR 側の「OSCルーター」が有効になっている場合は、無効（OFF）にしてください。

### Q2. モニターが「待機中 ○ (データ未着)」のまま動かない
* **原因**: SlimeVR からのパケットが届いていません。
* **対処法**:
  1. SlimeVR Server の「設定」→「OSC」→「VRChat OSC」が **有効** になっているか確認。
  2. ポートアウトが **`9000`**、ネットワークアドレスが **`127.0.0.1`** になっているか確認。
  3. Windows Defender ファイアウォールで `Unity.exe` の通信がブロックされていないか確認してください。

### Q3. 手を動かしたとき、人形の腕が左右逆に動く (鏡写しになる)
* **原因**: トラッカーの向き（正面Yaw角）の基準オフセットが逆転しています。
* **対処法**:
  * Inspector の `SlimeVRTestReceiver` ➡ **`Facing Yaw Offset` に `180`** を入力してください。

### Q4. 壁と人形の大きさが合わない / 足が地面にめり込む
* **対処法**:
  * メニュー `Tools` ➡ `Build All Wall Prefabs` を再実行してください。
  * 壁のブロックサイズが `0.46m`（全幅2.3m × 全高2.3m、足元Y=0接地）に再生成され、人形とピッタリ一致します。

### Q5. マウスで難易度ボタンをクリックしても反応しない
* **対処法**:
  * キーボードの **`[1]` (Easy)**、**`[2]` (Normal)**、**`[3]` (Hard)**、または **`[Space]`** を押すことでキーボードから直接スタートできます。

### Q6. カメラ位置を微調整したい
* **対処法**:
  * 実行中にキーボードの **`[F1]`** キーを押すと、調整HUDが表示されます。
  * `[W][A][S][D]` で前後左右、`[Q][E]` で上下、`[R][F]` でチルト角を変更できます。
  * 気に入った位置で **「現在位置を保存」** ボタンを押せば、次回以降もその位置で固定されます。
