# 要件定義 (Requirements)

## 1. 概要 (Overview)
* **タイトル**: **WallNut**
* **ジャンル**: 全身アクションゲーム（もじもじくん風）
* **プラットフォーム**: PC (画面はプロジェクターに出力)

## 2. プレイヤー環境・トラッキング仕様
* **VRゴーグル**: **不使用**。プロジェクターの映像を見ながらプレイする。
* **トラッキング機器**: SmolSlime (SlimeVR互換)
* **トラッキング箇所**: 計11点（両腕4点、両足4点、胴体2点、頭1点）
* **連携方法**: OSC通信（SlimeVRから直接UnityのUDP 9000番ポートへデータを送信）
* **キャラクターへの反映 (IKアプローチ)**:
  * SlimeVR側の計算結果（関節の回転データ）をOSCで受け取り、キャラクターの骨格ボーン（頭・腕・足）に直接コピー。
* **キャリブレーション機能**:
  * プレイヤーの身長・姿勢の個人差を補正するため、直立姿勢時の頭部高さ、肩高さ、足首角度を基準値としてワンキー記録（CキーまたはUIボタン）。

## 3. ゲームの目的・コア体験 (Core Experience)
* 迫りくる壁（障害物）の穴の形に合わせて、全身でポーズをとって通り抜ける。
* リズムやタイミングに合わせてポーズを切り替える体験。
* コンボシステム、成功回数、最終スコア、ランク評価（S+〜C）を表示。

## 4. 画面・カメラ設定
* **視点**: 三人称視点（キャラクターの背中を後ろから見る形）
* **キャラクター**: シンプルな人型ダミー（全身のポーズと顔の向きが分かりやすい赤い鼻付き棒人間）
* **UI**: 1920x1080解像度のプロジェクター用大画面UI（タイトル・カウントダウン・HUD・リザルト）

## 5. 主要なシステム・機能 (Main Features)
* **プレイヤーの移動制限**: 立ち位置は固定（横移動なし）。ポーズ（姿勢）のみで壁を避ける。
* **ステージ構成**: 1ステージあたり壁10枚。事前に用意した複数の壁の穴パターンからランダムに出現。
* **難易度設定機能**: タイトル画面から、壁の流れてくるスピードや間隔（Easy, Normal, Hard）を選択可能。
* **対応ポーズ一覧（全7種）**:
  1. `0: STAND` (棒立ち: 中央縦穴 / 白)
  2. `1: BANZAI` (バンザイ: 両手上 / 赤)
  3. `2: SQUAT` (しゃがみ: 足元広域穴 / スカイブルー)
  4. `3: T-POSE` (Tポーズ: 腕水平・十字穴 / エメラルドグリーン)
  5. `4: RIGHT ARM UP` (右腕上げ: 右腕上・左腕下 / イエロー)
  6. `5: LEFT ARM UP` (左腕上げ: 左腕上・右腕下 / シアン)
  7. `6: FLAMINGO` (片足立ち: 片足曲げ横突き出し / マゼンタ)
* **判定システム**: ボーン座標・角度計算ベースの自動判定（チャタリング防止タイマー付き）。
